# 🚀 Merin Consultancy Website (MCS) - Frontend

A modern and responsive frontend built with **Next.js**, designed for a marine consultancy company. This project focuses on performance, scalability, and clean UI using modern technologies.

---

## 🛠️ Tech Stack

- ⚡ Next.js (App Router)
- ⚛️ React.js
- 🎨 Tailwind CSS
- 🧩 shadcn/ui
- 🔄 Swiper.js (for sliders)
- 📦 Axios / Fetch API

---

## 📁 Project Structure

```
frontend/
├── app/              # Next.js App Router pages
├── components/       # Reusable UI components
├── components/ui/    # shadcn/ui components
├── public/           # Static assets
├── styles/           # Global styles
└── utils/            # Helper functions
```

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/MCS.git
cd MCS/frontend
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run development server

```bash
npm run dev
```

👉 App will run on:
http://localhost:3000

---

## 🧩 Adding UI Components (shadcn)

You can add new UI components using:

```bash
npx shadcn@latest add button
```

Example usage:

```tsx
import { Button } from "@/components/ui/button";
```
